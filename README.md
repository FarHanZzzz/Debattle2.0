# Debattle 2.0 — Clash of Departments

Premium event website for IUB Debate Club's inter-department parliamentary debate tournament.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion
